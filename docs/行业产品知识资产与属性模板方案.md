# 行业知识资产与业务使用场景方案

## 1. 范围与状态

属性模板场景第一期只配置一个示例行业：**一级行业「汽车制造行业」→ 二级行业「汽车零部件」**。行业路径在该原型中固定展示；正式接入时以稳定的行业 ID 存储，名称仅用于展示。FAQ 生成场景从产品列表、荣誉资质、企业概况和客户案例四个业务栏目选择具体数据条目。

另有两个存放在 `docs/` 下的属性模板 JSON 示例：[数控车床](数控车床_属性模板.json)与[建筑钢结构](建筑钢结构_属性模板.json)。它们作为现成模板展示在属性模板列表中，也可在“选择行业属性模板”弹窗的“JSON 示例模板”分组中按字段选择。JSON 未提供行业 ID，因此原型以“docs 示例”标明来源，不推断这两个产品的一级、二级行业归属。

| 资产 | 维护内容 | 消费位置 | 本期交付 |
| --- | --- | --- | --- |
| FAQ 生成来源 | 产品列表、荣誉资质、企业概况、客户案例中的数据条目 | 内容管理 → 常见问题 → AI 生成 FAQ | 可交互原型、端点映射 |
| 行业产品属性库 | 产品类别及可复用的属性项 | 产品管理 → 属性模板 → 新增属性模板 → 产品属性 | 可交互原型、端点映射 |
| 行业产品模型属性值库 | 产品下的规格名及该规格的可选值 | 产品管理 → 属性模板 → 新增属性模板 → 规格类型 | 可交互原型、端点映射 |
| 行业产品详情库 | 产品详情应填写的结构字段、字段说明和写作规则 | 产品管理 → 产品列表 → 产品编辑 → 扩展信息 → 产品描述 → AI 写作 | 方案文档；本期不做页面 |
| 资质与证书规范库 | 荣誉资质字段、录入规范和表格生成规则 | 内容管理 → 荣誉资质 → 编辑详情 → AI 写作 | 方案文档；本期不做页面 |

FAQ 原型入口为 `/`，属性模板原型入口为 `/attribute-templates`。数据为示例，不包含真实行业标准或客户证书。平台维护和发布行业资产，企业侧从已发布版本引用。

## 2. 行业产品属性库

### 层级和记录

`汽车制造行业 → 汽车零部件 → 产品分类 → 产品 → 属性项`。分类与产品按照 Excel 总索引组织，共 10 个系统分类、95 个产品条目。例如 `SYS-01_动力系统` 下包含活塞、火花塞、点火线圈和附件皮带。属性项是可加入模板的最小单位，产品只是组织和定位属性项的节点。

| 字段 | 说明 |
| --- | --- |
| `attributeId` | 稳定 ID，用于引用、去重和版本更新 |
| `industryPath`、`productCategoryId`、`productId` | 行业及产品归属 |
| `name`、`description` | 展示名称和使用说明 |
| `fieldType`、`unit` | 模板字段类型与单位，如 `number / mm` |
| `status`、`version` | 发布状态和平台版本 |

在“产品属性”页签点击“选择行业属性模板”，弹窗显示固定行业路径与产品树。左侧可按分类名或产品名筛选，点击分类时右侧展示该分类下所有产品的属性项；点击产品时只展示该产品的属性项。用户可跨产品勾选属性项。确认后，**每个属性项成为当前属性模板表中的一行**；保留来源产品和来源 `attributeId`，同一来源 ID 不重复加入。已有基础字段不受影响，用户可移除尚未保存的导入行。保存属性模板时再一并提交。正式实现应为导入字段设置默认显示状态，并将搜索、TDK 等现有模板配置继续交由模板编辑流程处理。

两个 JSON 示例分别包含 37 与 36 个字段，其中各有 15 个带 `code` 的系统基础字段。打开示例模板编辑页可查看全部字段；弹窗中只展示不带 `code` 的产品专属字段，避免把系统基础字段重复加入自定义模板。字段的 `attributeType`、`unit` 和由 `attributeValue` 拆出的有序可选值会随字段带入。JSON 中的下拉可选值属于**产品属性的选项**，不等同于“规格类型”页签的产品模型属性值规格；这两个 JSON 没有提供规格类型数据。

## 3. 行业产品模型属性值库

### 层级和记录

`汽车制造行业 → 汽车零部件 → 产品分类 → 产品 → 规格类型 → 属性值`。一个规格类型对应一组可选值，不把每个值拆成独立的规格行。例如“刹车片 → 尺寸”可包含 `180×70×16 mm`、`185×72×16 mm` 等多个值；“六角螺栓 → 尺寸”可包含 `M6×20`、`M8×30` 等值。两者虽然同名，但来源产品和规格 ID 不同。

| 字段 | 说明 |
| --- | --- |
| `specId`、`productId` | 规格稳定 ID 及所属产品 |
| `name`、`description` | 规格名和定义 |
| `displayType` | 展示类型，如文字 |
| `values[]` | 有序的可选值，值应保留原始单位和格式 |
| `status`、`version` | 发布状态和平台版本 |

在“规格类型”页签点击“选择行业属性值规格”，弹窗按产品树查找规格；规格行可展开查看全部值，并可跨产品勾选。确认后，**一个选中的规格类型成为模板的一行，整组 `values[]` 随行带入**。同一 `specId` 不重复加入。用户可在模板中移除导入行，保存时随模板提交。正式实现需校验同一规格下的值不重复、非空，且规格名称与单位表达一致。

## 4. 行业产品详情库（文档方案）

### 知识库存放

将平台维护的规范放入知识库分类 **「产品与服务 → 产品详情规范」**。每条规范绑定行业路径，可进一步绑定产品分类或产品；记录应包含 `standardId`、标题、适用范围、版本、发布状态、生效时间、字段清单、写作说明和来源说明。仅已发布且适用当前行业/产品的版本进入 AI 写作上下文。规范是写作规则，产品的真实参数仍以当前产品数据及已审核知识为准。

### 产品详情字段建议

| 字段组 | 建议字段 | 填写与生成要求 |
| --- | --- | --- |
| 基本信息 | 产品名称、型号、产品类别、产品定位 | 与产品主数据一致；型号不得由 AI 推断 |
| 应用信息 | 适用行业、适用车型/设备、使用场景、解决的问题 | 区分“已验证适配”和一般应用建议 |
| 技术信息 | 关键参数、规格值、单位、允许公差、材料、制造工艺 | 优先读取属性模板、规格值及产品已录入数据；数值必须带单位 |
| 性能与优势 | 主要功能、性能指标、差异化特点 | 有测试或资料依据才写定量承诺 |
| 合规与证明 | 执行标准、认证、检测报告、证书适用范围 | 只能引用有效且适用于该产品的资料 |
| 交付与使用 | 包装、安装、使用条件、维护方式、售后服务 | 按真实交付条件填写，不生成不存在的承诺 |
| 内容素材 | 图片、视频、图注、下载资料、常见问题 | 媒体需与当前型号匹配，文字说明可审阅 |

每个字段的规范记录还应说明：是否必填、允许的值类型、单位、示例、数据来源优先级、禁写内容、缺失时的处理方式。正文建议按“产品是什么 → 适用什么场景 → 关键参数与特点 → 使用/交付说明”的顺序组织；不得捏造型号、参数、认证或适用车型。缺少事实时保留待补充提示。

### AI 写作取用流程

触发点：**产品管理 → 产品列表 → 产品编辑 → 扩展信息 → 产品描述 → AI 写作**。

1. 读取当前产品的行业 ID、类别、已录入字段、属性模板、规格值和审核过的资料。
2. 从「产品与服务 → 产品详情规范」检索适用当前行业及产品的全部已发布规范；优先级为产品专属、产品类别、行业通用。记录引用的规范 ID 和版本。
3. 将字段结构、写作要求、产品事实及来源组织为提示词。规范只约束结构和表达，事实以产品数据为准；冲突时提示人工核对。
4. 生成产品描述草稿及缺失字段清单，由用户核对并保存。规范更新不自动覆盖已发布的产品描述。

## 5. 资质与证书规范库（文档方案）

### 知识库存放

将平台维护的字段要求和录入规范放入 **「资质与认证体系 → 荣誉资质」**。规范可按证书、产品认证、专利与荣誉等类型拆分，但应保持统一的字段定义。每条规范记录包含 `standardId`、类型、适用行业、字段清单、填写规则、表格列顺序、版本、生效时间及发布状态。客户的实际证书文件与该规范分开保存。

### 荣誉资质字段建议

| 字段 | 要求 |
| --- | --- |
| 资质/证书名称、类型 | 按证书原文填写；区分企业资质、产品认证、专利和荣誉 |
| 获证主体、颁发机构 | 与证明文件一致；不得把关联方证书写成企业持有 |
| 证书编号、发证日期、有效起止日期 | 保留原始格式；未知值留空，不臆造编号或日期 |
| 适用范围、关联产品/型号、地区 | 明确覆盖对象；产品认证不可扩写成全公司认证 |
| 当前状态 | 在有效期、已过期、撤销、待核实等；按现有证据判断 |
| 证明文件、可核验地址、备注 | 关联文件及来源，标注需要人工核验的内容 |

展示表格建议列为：**名称｜类型｜获证主体｜颁发机构｜证书编号｜适用范围｜有效期｜状态｜证明文件**。字段缺失时显示“待补充”或留空，不用虚构值补齐。证书过期或撤销时不能表述为当前有效资质。上传文件需经过人工确认和必要的权限检查。

### AI 写作取用流程

触发点：**内容管理 → 荣誉资质 → 编辑详情 → AI 写作**。

1. 读取当前编辑记录、关联证书文件的已确认字段、主体与行业。
2. 从「资质与认证体系 → 荣誉资质」读取适用的全部已发布字段规范与表格规则，记录规范 ID 和版本。
3. 依据证据生成结构化字段表格及简短描述；只填可核实的值，同时标出缺失、过期或主体不符的项目。
4. 用户核对表格后保存为草稿，再按现有内容审核流程发布。AI 不直接替代资质真实性审核。

## 6. FAQ 按业务条目生成与保存

### 来源栏目与列表字段

入口：**内容管理 → 常见问题 → AI 生成 FAQ**。弹窗左侧按菜单栏和子菜单组织四类来源，右侧列出该栏目下可选的数据条目；切换栏目不清空已选项。

| 菜单 → 子菜单 | 条目列表展示字段 |
| --- | --- |
| 产品管理 → 产品列表 | 缩略图、产品名称、分类、字段 |
| 内容管理 → 荣誉资质 | 分类、荣誉名称 |
| 内容管理 → 企业概况 | 概要图片、内容标题、所属分类 |
| 内容管理 → 客户案例 | 案例名称、案例分类 |

每个来源条目至少包含稳定 `sourceId`、栏目 `sourceMenu`、标题、分类和可读取的正文或结构字段；产品与企业概况附图片地址，产品附字段清单。列表可搜索并勾选具体条目，可跨栏目选择。已保存过 FAQ 的来源显示“已生成 N 次”，计数来自已入库 FAQ 的来源关联，不把尚未保存的候选计入。再次选择已生成来源属于重新生成，应创建新的 FAQ，不更新或覆盖旧记录。

### 生成、确认与版本

1. 用户勾选具体数据条目，点击“生成 N 条 FAQ”。**每个选中条目生成一条候选 FAQ**，候选保留 `sourceId`、`sourceMenu`、来源标题、问题、答案及第几次生成信息。原型使用本地示例问答模拟 AI 输出。
2. 生成完成后进入结果列表。候选默认勾选，用户可搜索、查看完整问答、编辑问题与答案，并取消不想保存的条目。
3. 用户在“保存到分类”中选择已有 FAQ 分类（默认“常见问题”），点击“确认保存”后，仅把当前选中的候选创建为该分类下的 FAQ 草稿，保留来源关联与生成次数；未确认保存的候选不计入“已生成”。新草稿可走原有编辑、发布流程。
4. 已生成来源再次入选时，生成结果标注下一次生成序号。保存时新增独立草稿，保留此前同来源的所有已入库 FAQ；即使问题文本相同，也不因重复而覆盖旧问答。

正式接入时，预览请求仅提交所选 `sourceId`，服务端按栏目及用户权限读取当前源数据并生成，不信任浏览器传入的正文。批量保存请求只接收用户确认的候选，校验问题和答案非空，持久化来源 ID、来源记录版本、生成时间与模型版本，便于审阅和追溯。某个来源删除或改名后，已保存 FAQ 的来源快照仍应可查看。

### 接口与验收

FAQ 原型的数据槽位及动作端点见 [IndustryFaqPage.meta.json](../src/IndustryFaqPage.meta.json)：读取 FAQ 列表、按栏目读取来源条目、生成候选预览、批量创建草稿，以及后续编辑、发布、删除。

验收重点：四个栏目显示对应字段；跨栏目选择保留；选中多少个来源就生成多少条候选；候选可查看与修改；确认保存前不入库；再次进入可见“已生成”标签；重新生成保存为新 FAQ，旧 FAQ 保持不变。

## 7. 原型接口与后续实现

属性模板原型的数据槽位与动作接口映射在 [AttributeTemplatePage.meta.json](../src/AttributeTemplatePage.meta.json)。两个原型当前都只用本地示例数据演示，不发真实请求。生产接入时，行业树和属性/规格查询应返回已发布版本并按租户授权；模板保存请求需带来源 ID、来源版本及用户调整后的字段配置。产品详情与荣誉资质的知识库查询、AI 写作接口本期未在原型中声明，待对应页面接入时按上述触发点定义，并保留规范引用记录以便审核与追溯。

属性模板验收重点：两个选择弹窗能按固定行业浏览产品，跨产品选择后分别回填产品属性和规格类型；规格值整组保留；重复来源不能再次加入；模板可保存并在列表中看到。产品详情和荣誉资质只检查文档中的字段、分类路径及 AI 取用流程，不要求本期页面实现。

## 8. Excel 属性模板映射（2026-10-30）

从 `00_模板总索引.xlsx` 读取系统分类及产品顺序，再读取对应产品 Excel 的“字段定义”工作表，合计 2470 条字段。原型保留表格中的字段类型原文，不使用同目录 JSON 的类型重命名。相同产品名出现在不同系统时，按系统和产品 ID 分开组织。

| Excel 列 | 页面 / 数据字段 |
| --- | --- |
| 所属系统、品类 | 左侧系统分类、产品节点 |
| 数据项/字段名 | 属性名 `name` |
| 字段类型 | 类型 `type` |
| 说明 | 说明 `description`（选填） |
| 示例值 | 示例值 `example`（选填，保留数值 0） |
| 单位、选项值 | 单位、有序可选值 |

选择弹窗与导入后的产品属性列表均展示说明和示例值。新增属性时可填写，导入后可修改，也可留空；保存、编辑与复制模板保留这两项。Excel 的字段定义用于属性项，示例数据工作表不作为产品记录导入；规格类型仍使用已有规格示例。
