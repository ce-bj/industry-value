# 企业画像与外贸客户洞察：功能说明

**给谁**：产品、设计、开发、测试。
**讲什么**：每个功能怎么做：入口、数据从哪来、页面怎么交互、结果按什么规则算出来。
**运营要补的内容**（行业清单、方案文案、四个被、产品字典等）见《企业画像与外贸客户洞察_运营数据清单》，本文用「运营清单第 N 项」指代。
**原型**：`/overview/` → `/enterprise-profile/`；`/customer/market-opportunity/` → `/customer/trade-insight/`。

---

## 1. 入口与整体流程

```
概况 › 版本下方「企业画像」卡片
   └─ 未评测：开始评测 → 7 步诊断 → 结果页
   └─ 已评测：查看画像 → 结果页 → 重新填写 / 单步修改 → 结果页

客户管理 › 外贸客户洞察 › 市场与机会
   └─ 名单右上角「更多」→ 外贸客户洞察（公司数据）
   └─ 名单中「查看企业详情」→ 企业详情页（本期原型不做跳转）
```

- 概况页卡片两种状态：
  - **待评测**：显示 7 步的名称，按钮「开始评测」。
  - **已完成**：显示企业名称 · 所属行业 · 方案名称，数字化 / 全球化等级、信任评分、更新时间，按钮「查看画像」。
- 整张卡片可点击，进入企业画像页。

## 2. 七步诊断

顶部是 7 个步骤的进度条，底部是「上一步 / 下一步」，最后一步按钮为「完成评测，查看结果」。每一步必填项未填时，点「下一步」在卡片下方提示缺什么，不能进入下一步。

### 2.1 第 1 步　企业身份识别

步骤卡片顶部提示「已读取 N 个网站的「网站管理 › 网站设置 › 网站信息」」；所有网站都没填公司名称时，提示后加「均未填写公司名称，请手动输入」。

#### 企业名称

- **来源**：网站管理 › 网站设置 › 网站信息 › **公司名称**。一个企业可能有多个网站，每个网站各有一个公司名称。
- **控件**：可输入的下拉框，右侧下拉按钮。
  - 下拉列出各网站的公司名称（按网站顺序），每项下方小字显示来源：「来自 英文站」，或多个网站时显示「来自 2 个网站：英文站、日语站」。
  - 多个网站的公司名称相同时只列一次。
  - 公司名称为空的网站不列出；所有网站都为空时不显示下拉按钮。
- **默认值**：第一个网站的公司名称。「第一个」按网站管理中网站列表的排序；第一个网站为空时，取下一个不为空的。
- **用户操作**：从下拉中选择其他网站的公司名称，或直接在框里输入（输入的内容不必在下拉中）。
- **校验**：必填，去掉首尾空格后不能为空。
- **不回写**：这里改的企业名称只保存在企业画像里，不修改网站信息。

#### 所属行业

一个企业可以有多个所属行业。

- **来源**：各网站的 网站管理 › 网站设置 › 网站信息 › **所属行业**。每个网站可以有主行业和额外行业。
- **汇总规则**：
  1. 按网站列表顺序，每个网站内按行业顺序，**全部列出**。
  2. 相同的「一级 / 二级」只保留一个，记下来源网站。
  3. 未选到二级的行业不带入。
  4. **最多保留 10 个**；超过时保留前 10 个，并提示「网站信息共 N 个，已保留前 10 个」。
- **显示**：已选行业以标签排成一行，标题旁显示「已选 N / 10」。每个标签：
  - 显示「一级行业 / 二级行业」，悬停显示来源网站（或「手动添加」）。
  - 已有完整行业内容的行业带图标。
  - 可点 × 移除。
- **主行业**：
  - 第一个行业为**主行业**，标签前显示「主行业」。
  - 其他行业的标签前有「设为主行业」，点击后移到第一个。
- **添加**：下方「一级行业 › 二级行业」两个可搜索下拉加「添加行业」按钮。
  - 必须选到二级才能添加，已有的不能重复添加。
  - 满 10 个时按钮不可用。
  - 已有完整行业内容的行业在下拉中置顶并带图标。
- **校验**：
  - 至少 1 个，否则提示「请至少选择一个「所属行业」，需选到二级行业」。
  - 最多 10 个。
- **影响**：
  - **主行业**决定行业平均信任评分（运营清单第 5 项）和四个被（第 6 项）。
  - **全部所属行业**决定主营产品用哪些产品字典匹配（第 7 项），按行业顺序依次查。
- **结果页显示**：方案卡片显示主行业；「企业画像」一段列出全部所属行业，并注明「第一个为主行业」。

示例（原型数据）：

| 网站（排序） | 公司名称 | 所属行业（网站信息） |
|---|---|---|
| 1 中文站 xinchi-auto.cn | 宁波鑫驰汽车零部件有限公司 | 汽车制造行业 / 汽车零部件；汽车制造行业 / 汽车后市场 |
| 2 英文站 xinchi-autoparts.com | Ningbo Xinchi Auto Parts Co., Ltd. | 未设置 |
| 3 俄语站 xinchi-auto.ru | 宁波鑫驰汽车零部件有限公司 | 汽车制造行业 / 汽车零部件；机械设备制造 / 通用零部件 |

→ 企业名称下拉两项：
- 「宁波鑫驰汽车零部件有限公司」，来自 2 个网站：中文站、俄语站
- 「Ningbo Xinchi Auto Parts Co., Ltd.」，来自 英文站

默认选中第一项。

→ 所属行业 3 个：
- 汽车制造行业 / 汽车零部件（主行业，来自中文站、俄语站）
- 汽车制造行业 / 汽车后市场
- 机械设备制造 / 通用零部件

#### 重置为网站信息

- **首次填写**：第 1、2 步的值从网站信息带入。
- **重新填写**：带入**上次保存的值**，不自动换成网站信息的最新内容。
- **重置按钮**：第 1 步和第 2 步顶部的提示条右侧有「重置为网站信息」，点击后按当前网站信息重新带入。
  - 第 1 步：重置企业名称和所属行业（规则同上）。
  - 第 2 步：只重置主营产品（规则见 2.2），员工人数、年营收不变。
  - 重置后显示「已按网站信息重置…」，切换步骤后消失。
- **提示条文字**：
  - 首次填写：「已读取 N 个网站的「网站管理 › 网站设置 › 网站信息」」
  - 重新填写：「已带入上次保存的企业名称与所属行业」或「已带入上次保存的主营产品」

### 2.2 第 2 步　规模与产品

#### 员工人数、年营收规模

单选卡片，必填。

- 员工人数：<50人 / 50-200人 / 200-500人 / 500-2000人 / >2000人
- 年营收：<¥1000万 / ¥1000万-5000万 / ¥5000万-2亿 / ¥2亿-10亿 / >¥10亿

#### 主营产品

- **来源**：所有网站的 网站管理 › 网站设置 › 网站信息 › **主营产品**（标签字段），做多网站聚合。
- **聚合规则**：
  1. 按网站列表顺序，依次取每个网站的主营产品标签。
  2. 去掉首尾空格；忽略大小写、全角 / 半角差异后相同的视为同一个，只保留第一次出现的写法。
  3. 按第一次出现的顺序排列。
- **标签显示**：
  - 悬停时显示来源（「来自 中文站、英文站」或「手动添加」）。
  - 是别名的，悬停时还显示「按「制动鼓」统计」。
  - 产品字典中没有的，标签标黄并带「未收录」，悬停说明「市场与机会中显示待归类」。
- **添加**：输入框可直接输入，也可从下拉提示中选择全部所属行业的产品字典里还没选的产品（运营清单第 7 项）；按回车或点「添加」加入，重复的（忽略大小写、全半角）不再加入。
- **删除**：点标签上的 ×。
- **不回写**：这里的增删只影响企业画像，不修改各网站的网站信息。
- **校验**：至少 1 个，否则提示「请至少保留一个「主营产品」」（「市场与机会」按这些产品取数）。

示例（原型数据）：

| 网站 | 主营产品 |
|---|---|
| 中文站 | 制动盘、制动鼓、轮毂单元 |
| 英文站 | 制动盘、Brake Drum、轮毂轴承 |
| 俄语站 | 「制动盘 」（带空格）、定制改装件 |

→ 聚合结果：制动盘、制动鼓、轮毂单元、Brake Drum、轮毂轴承、定制改装件。
- 「制动盘」出现 3 次，合并为 1 个。
- 「Brake Drum」是「制动鼓」的别名，在市场与机会中并入「制动鼓」，不重复计数。
- 「定制改装件」不在字典中，标「未收录」。

### 2.3 第 3–7 步

| 步骤 | 字段 | 控件 | 选项 |
|---|---|---|---|
| 3 客户与经营模式 | 目标客户类型 | 单选卡片 | Tier1/主机厂、售后市场、分销商/贸易商、混合模式 |

## 3. 结果怎么算

### 3.1 方案：共 3 个

方案只由**数字化等级**和**全球化等级**决定，共 25 种组合：

| 数字化 \ 全球化 | G1 | G2 | G3 | G4 | G5 |
|---|---|---|---|---|---|
| L1 | B | B | C | C | C |
| L2 | B | B | C | C | C |
| L3 | C | C | C | C | C |
| L4 | C | C | A | A | A |
| L5 | C | C | A | A | A |

| 方案 | 规则 | 组合数 |
|---|---|---|
| A 全球化加速 | 数字化 ≥ L4 **且** 全球化 ≥ G3 | 6 |
| B 基础建设 | 数字化 ≤ L2 **且** 全球化 ≤ G2 | 4 |
| C 精准深耕 | 不满足 A、B 的其余情况 | 15 |

每个方案展示的文字（方案名称、方案说明、阶段标签）来自运营清单第 2 项。

### 3.2 指标

| 指标 | 算法 |
|---|---|
| 数字化差距 | 5 − 数字化等级 |
| 全球化差距 | 5 − 全球化等级 |
| 信任评分 | 数字化等级 × 8 + 全球化等级 × 7 + 获客渠道数 × 5 + 15，结果限制在 20–95 |
| 与行业对比 | 取主行业的平均信任评分（运营清单第 5 项）：低于平均显示「行业 48分 · 差距 N 分」，否则「行业 48分 · 已超越」；该行业没有平均分时显示「本行业均值待补充」 |
| 核心目标 | 显示运营清单第 4 项对应的标签 |

### 3.3 关键发现、First Win 目标（暂不做）

结果页不显示「关键发现」和「First Win 目标」（含时限、成功信号、总周期），原型已去掉。规则与文案保留在运营清单第 2、3 项，以后需要时再启用。

### 3.4 三个方案各一个示例

以下示例的所属行业为汽车零部件，行业平均信任评分 48。

| | A 示例 | B 示例 | C 示例 |
|---|---|---|---|
| 数字化 / 全球化 | L4 / G3 | L2 / G1 | L3 / G2 |
| 获客渠道 | 展会、B2B平台、LinkedIn开发（3 个） | 展会（1 个） | B2B平台、海关数据（2 个） |
| **方案** | **A-全球化加速** | **B-基础建设** | **C-精准深耕** |
| 方案说明 | 数字化L4+全球化G3基础扎实，核心瓶颈在品牌和获客效率 | 数字化L2+全球化G1需要先补基础，再谈增长 | 数字化L3+全球化G2基础OK但获客渠道单一，需要精准突破 |
| 数字化差距 | 1 级 | 3 级 | 2 级 |
| 全球化差距 | 2 级 | 4 级 | 3 级 |
| 信任评分 | 4×8+3×7+3×5+15 = **83**，已超越 | 2×8+1×7+1×5+15 = **43**，差距 5 分 | 3×8+2×7+2×5+15 = **63**，已超越 |

## 4. 结果页

自上而下三段，右上角「重新填写」。

| 段 | 内容 |
|---|---|
| 01 评测结果 | 方案卡片（方案标签、名称、说明、企业名称 · 一级行业 / 二级行业 · 员工人数 · 年营收）；4 个指标（数字化、全球化、信任评分、核心目标） |
| 02 企业画像 | 按 7 步分行显示填写内容，每行右侧「修改」 |
| 03 网站需要具备的内容 · 四个被 | 按主行业取运营清单第 6 项的 4 行；「最易失守」的一行高亮，底部说明引用该行 |

- **该行业没有四个被内容**：第 03 段显示「「{二级行业}」的四个被内容整理中，可先查看上方评测结果。」，其他段正常显示。
- **重新填写**：带入上次全部答案，从第 1 步开始；完成后覆盖原结果，评测次数 +1，更新时间刷新。过程中可点「取消重新填写」回到结果页，原结果不变。
- **单步修改**：点某一行的「修改」，带入上次答案并直接跳到该步，之后照常走到第 7 步完成。
- **重新进入第 1、2 步时**：企业名称、所属行业、主营产品显示上次保存的值；需要网站信息的最新内容时点「重置为网站信息」（见 2.1）。

### 4.1 网站信息变更后

- **快照**：完成评测时，记下当时各网站网站信息的快照：公司名称、所属行业、主营产品（均为多网站汇总后的结果）。
- **比较**：之后每次打开结果页，用当前网站信息与快照比较。比较时忽略首尾空格、大小写、全半角差异。
- **有变更时**：评测结果**不自动更新**，结果页顶部显示黄色提示条：
  - 标题：「网站信息有变更，评测结果未自动更新」
  - 逐项列出变更，例如「主营产品：新增 刹车片」「所属行业：新增 汽车制造行业 / 新能源汽车」「公司名称：移除 …」
  - 右侧按钮「重新评测」：等同「重新填写」，从第 1 步开始，带入上次保存的值。用户在第 1、2 步点「重置为网站信息」带入最新内容。
- **完成重新评测后**：快照更新为当前网站信息，提示条消失。
- **原型演示**：结果页地址加 `?siteChanged=1`，模拟中文站新增主营产品「刹车片」和行业「新能源汽车」。

## 5. 市场与机会

位置：客户管理 › 外贸客户洞察 › **市场与机会**（左侧菜单新增项，排第一）。

### 5.1 主营产品 → 企业数据的关联逻辑

```
企业画像的主营产品（多网站聚合，见 2.2）
   │ 按全部所属行业的产品字典匹配
   ▼
标准产品 → 海关编码（+ 报关描述关键词）
   ├─ 海关进口数据，按进口国汇总 ───────▶ 目标市场进口趋势
   ├─ 海关进口数据，按进口商汇总 ───────▶ 谁在买（海关数据信号）、外贸客户洞察
   └─ 全球企业库，按行业 / 产品匹配 ─────▶ 谁可能会买（全球企业发现）
谁在买 ∪ 谁可能会买（按企业去重）───────▶ 客户池总览
```

### 5.2 四个模块

| 模块 | 怎么做 |
|---|---|
| 客户池总览 | 见 5.3。 |
| 目标市场进口趋势 | 按主行业取运营清单第 9 项的表，按进口额从高到低：横条长度 = 近 12 个月进口额，横条后显示**进口额**（统一美元，如 $3.20B），再标机会等级（运营清单第 8 项规则）；下方每国一张卡片：进口额、同比、采购商数量；底部一段行业洞察与重点国家建议。 |
| 谁可能会买 | 全球企业库中行业 / 产品匹配的企业，按匹配度（运营清单第 8 项规则）从高到低；≥ 90% 标红；显示国家、规模、营收、有无海关记录。 |
| 谁在买 | 按主营产品列出近 3 个月的全部海关数据，按进口商汇总，见 5.5。 |

### 5.3 客户池总览

- **主营产品只读**：
  - 取企业画像第 2 步保存的主营产品，本页不能添加或删除。
  - 标题旁显示「（来自企业画像 · 主行业 {二级行业} 等 N 个行业）」，后面有「去企业画像修改产品」链接。
  - 还没填写企业画像时，用示例产品（制动盘、制动鼓、轮毂单元），标题旁显示「尚未填写企业画像，以下为示例产品」，链接为「去填写企业画像」。
- **产品 ↔ 英文名 ↔ 海关编码**：一张表，每个主营产品一行，列为：主营产品｜英文名（用于查海关编码）｜海关编码｜编码名称 / 说明。
  - **英文名默认值**：
    1. 主营产品按全部所属行业的产品字典查到标准产品的，取该产品的**标准英文名**（运营清单第 7 项），如 制动盘 → Brake Disc。
    2. 字典查不到、但本身是英文的，用原文，如 Custom Rotor Kit。
    3. 其余为空，显示「未填写」。
  - **修改英文名**：
    - 点「修改」（为空时为「填写」）变成输入框，回车或「保存」生效，Esc 或「取消」放弃。
    - 改过的英文名后显示「已修改」，悬停可看默认值；旁边有「恢复默认」。
    - 保存为空或与默认值相同，视为恢复默认。
    - 修改按企业保存，下次打开仍生效；不修改企业画像里的主营产品，也不修改产品字典。
  - **用英文名查海关编码**：按英文名在全部所属行业的产品字典中查（比对标准英文名、标准名、别名，忽略大小写、空格、全半角）。
    - 查到：显示海关编码与编码名称。
    - 多个主营产品查到同一产品（如「制动鼓」和「Brake Drum」都是 Brake Drum），后面的注明「与「制动鼓」为同一产品，只计一次」。
    - 查不到：显示「待归类 —— 英文名未查到海关编码，不计入客户池」；英文名为空时显示「待归类 —— 请填写英文名」。
  - **示例**：主营产品「刹车蹄」字典未收录，英文名默认为空（待归类）；用户填写 Brake Pad 后查到「刹车片」，海关编码 8708.30，计入客户池。
- **4 个数**：
  - 客户池总量：已匹配产品的可触达企业数之和，按企业去重。
  - 可数 / 可推算 / 只能定性三档占比。
  - 待归类的产品不计入。
- **底部说明**：「共 N 个品类计入客户池（另有 M 个待归类）· 最近更新 {时间}」。
- **重新获取名单**：按当前产品重新取数，并刷新更新时间。

### 5.5 谁在买：按主营产品列出全部海关数据（近 3 个月）

**规则**：根据企业画像的主营产品，取海关数据中这些产品近 3 个月的**全部**进口记录，按进口商汇总后全部列出，不只取前几家。

**1. 取哪些记录**

| 条件 | 规则 |
|---|---|
| 产品 | 主营产品 → 产品字典 → 标准产品 → 海关编码；记录的海关编码属于这些编码，且报关描述命中该产品的关键词。字典未收录（待归类）的产品不取数。 |
| 时间 | 近 3 个月：截止到海关数据最新的完整月份，往前 3 个自然月。例：数据截至 2026-11-30，近 3 个月 = 2026-09-01 至 2026-11-30。 |
| 原产国 | 不限。全部原产国都列，包括从其他国家采购的进口商，用于发现竞争对手的客户。 |
| 进口国 | 不限。 |

**2. 每家进口商一行**（只列近 3 个月有记录的进口商）

| 字段 | 怎么算 |
|---|---|
| 进口商、国家 | 海关数据中的进口商名称（按统一企业 ID 合并不同写法）和目的国 |
| 匹配产品 | 这家买了我方哪些标准产品 |
| 近 3 月交易笔数 | 符合条件的记录数 |
| 近 3 月进口金额 | 合计，统一折算美元 |
| 近 3 月进口数量 | 合计，按单位分开显示（件、套、千克） |
| 主要原产国 | 近 3 月金额最大的原产国 |
| 最近交易日期 | 最新一条记录的日期 |
| 较前 3 个月变化 | （近 3 月金额 − 前 3 月金额）÷ 前 3 月金额。前 3 月为 0 的显示「新增买家」 |
| 信号强度 | 按运营清单第 8 项规则；「新增买家」建议按「高」 |
| 一句解读 | 可由数据自动生成的（如「首次从亚洲采购」「供应商数量减少」）自动生成；来自情报的注明来源 |

**3. 排序与展示**

- **排序**：默认按近 3 月进口金额从高到低，可切换为按变化幅度排序。
- **市场与机会卡片**：显示前 7 家。
- **查看全部**：点卡片右上角「更多 ›」（见 5.4），进入外贸客户洞察的「公司数据」，自动带入两个条件：
  - 交易日期 = 近 3 个月
  - 每个主营产品一个「产品：{英文名}」条件

  列出全部进口商，每页 20 家。
- **单家明细**：在外贸客户洞察列表点「查看详情」，看该进口商近 3 个月的每一条记录，字段为：交易日期、报关产品描述、海关编码（8–10 位）、数量、金额、原产国、出口商、出口港 → 进口港。
- **页面标注**：「数据截至 {日期} · 近 3 个月（{起} 至 {止}）」。

## 6. 外贸客户洞察

在现有外贸客户洞察页面上，「公司数据」页签支持从市场与机会名单右上角的「更多」跳入。

- **列表每行**：客户名称、国家 + 角色、产品描述（报关原文）、HS 编码、与我方产品匹配的交易次数、交易总金额、收藏、查看详情。
- **与我方产品匹配**：交易的海关编码属于我方产品对应的编码，且报关描述命中产品字典的关键词，才计入次数和金额。
- **收藏**：与左侧菜单「我的收藏」为同一份数据，点击切换「收藏 / 已收藏」。
- **查看详情**：弹窗显示匹配交易次数、交易总金额、HS 编码、原产国、出口港 → 进口港，以及近期交易（日期、产品、数量、金额）。
- **从「更多」进入**（见 5.4）：
  - **页面顶部**：提示来源与条件，左侧「返回市场与机会」。
  - **已选条件**：每个产品关键词一个「产品：{英文名}」，如「产品：Brake Disc」，可单独移除；点「全部」清空所有条件。
  - **从海关数据信号进入**：交易日期自动填为近 3 个月，并显示在筛选区和已选条件中。
  - **按产品关键词筛选**：企业的报关产品描述命中任一产品才列出。用产品字典（运营清单第 7 项）中该产品的报关描述关键词、标准名、别名做包含匹配，忽略大小写，例如「制动盘」命中 BRAKE DISC、ROTOR、DISCO DE FRENO（西语）、BREMSSCHEIBE（德语）。
  - **每行**：多显示一行「匹配产品：Brake Disc、Brake Drum」。
  - **英文名不在字典中时**：按英文名原文在报关描述中做包含匹配。
  - **没有结果时**：显示「没有符合条件的公司，请调整筛选条件。」
- **从左侧菜单直接进入**：不带条件，行为与现有页面一致。

**企业对应**：谁可能会买来自全球企业库，谁在买和外贸客户洞察来自海关数据。同一企业在两边的名称可能不同，需要统一企业 ID 对照（由数据团队提供），「查看企业详情」按 ID 打开企业详情页；没有对照时按「企业名称 + 国家」匹配。
