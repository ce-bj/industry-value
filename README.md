# 行业知识使用场景原型

这是独立的前端原型项目，包含“常见问题”AI 生成流程，以及“属性模板”中选择行业产品属性和规格值的流程。

## 安装与运行

需要 Node.js 18 或更高版本、npm，以及该 GitHub 仓库的读取权限。

```bash
git clone https://github.com/ce-bj/industry-value.git
cd industry-value
npm ci
npm run dev
```

启动后打开 <http://localhost:1235/> 查看常见问题，打开 <http://localhost:1235/attribute-templates> 查看属性模板。若 1235 端口已被占用，Vite 会在终端显示实际使用的端口；请以终端地址为准。

## 测试与构建

```bash
npm test          # 检查 FAQ 选择与行业属性/规格导入
npm run build     # TypeScript 检查并构建到 dist/
npm run preview   # 在 http://localhost:4173/ 预览构建结果
```

这是前端交互原型，数据保存在页面内存中；刷新后会恢复示例数据。原型不连接真实 AI 模型或后台接口。

## 原型交互

点击“AI 生成 FAQ”后，可在“企业知识”和“行业知识库”两个 Tab 中勾选知识库、一级分类或二级分类。每级显示当前知识条目数，选择可跨 Tab 保留。点击“生成 FAQ”后，先看到结果数量，再点击“查看生成结果”进入大列表。可搜索、查看完整问答、修改内容、勾选指定项目或全选当前筛选结果，然后点击“加入常见问题”。加入的项目以草稿状态出现在主列表中，未加入的候选可从工具栏继续查看。重新生成会替换待处理结果。

当前原型用示例知识的事实生成候选，不调用真实模型或后台接口。生产对接时，预览接口只传所选知识 ID，服务端读取已授权的当前知识内容生成，不能信任浏览器提交的正文。接口映射在 [IndustryFaqPage.meta.json](src/IndustryFaqPage.meta.json)。

## 行业属性模板原型

在“产品管理 → 属性模板”点击“新增自定义模板”。“产品属性”页签的“选择行业属性模板”可按产品树跨产品选择属性项，每项加入模板一行；“规格类型”页签的“选择行业属性值规格”可展开查看规格的全部可选值，选中后整组值加入模板一行。第一期示例行业固定为“制造业 → 汽车零部件”。保存后可在列表中继续编辑；同一来源项不能重复加入。

FAQ 生成、行业属性模板、产品详情规范与荣誉资质规范的完整方案见 [行业知识资产与业务使用场景方案](docs/行业产品知识资产与属性模板方案.md)。产品详情规范与荣誉资质规范本期仅作文档，不做页面。属性模板的原型端点映射在 [AttributeTemplatePage.meta.json](src/AttributeTemplatePage.meta.json)。
