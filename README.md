# 行业知识使用场景原型

这是独立的前端原型项目，包含“常见问题”AI 生成流程，以及“属性模板”中选择行业产品属性和规格值的流程。

## 安装与运行

需要 Node.js 18 或更高版本、npm，以及该 GitHub 仓库的读取权限。

```bash
git clone https://github.com/ce-bj/industry-value.git
cd industry-value
npm ci
npm run dev
```

启动后打开 <http://localhost:1235/> 查看常见问题，打开 <http://localhost:1235/attribute-templates/> 查看属性模板。若 1235 端口已被占用，Vite 会在终端显示实际使用的端口；请以终端地址为准。

## 测试与构建

```bash
npm test          # 检查 FAQ 按来源逐条生成与行业属性/规格导入
npm run build     # TypeScript 检查并构建到 dist/
npm run preview   # 在 http://localhost:4173/ 预览构建结果
```

`dist/` 已纳入 Git。若远端只提供静态文件，拉取仓库后无需安装依赖或重新构建，直接在仓库目录运行：

```bash
python3 -m http.server 4180 --bind 0.0.0.0 --directory dist
```

`dist/attribute-templates/index.html` 使静态服务器也能打开“产品管理 → 属性模板”并支持刷新该页面。修改源码后，维护者需运行 `npm run build`，将更新后的 `dist/` 与源码一起提交；远端拉取最新提交即可使用新页面。

这是前端交互原型，数据保存在页面内存中；刷新后会恢复示例数据。原型不连接真实 AI 模型或后台接口。

## 原型交互

点击“AI 生成 FAQ”后，可从“产品管理 → 产品列表”和“内容管理 → 荣誉资质 / 企业概况 / 客户案例”四个栏目中选择具体数据条目，选择可跨栏目保留。产品显示缩略图、名称、分类和字段；企业概况显示概要图片、内容标题和所属分类；荣誉资质显示分类和荣誉名称；客户案例显示案例名称和案例分类。已保存过 FAQ 的条目带“已生成 N 次”标签，再次选择会生成新 FAQ。

每个选中的数据条目生成一条 FAQ。生成完成后进入结果列表，可查看、修改问答并决定保存哪些条目；点击“确认保存”才会创建常见问题草稿。再次生成不会覆盖已保存的 FAQ。当前原型使用示例内容模拟生成，不调用真实模型或后台接口。生产对接时，预览接口只传所选条目 ID，服务端读取有权访问的源数据。接口映射在 [IndustryFaqPage.meta.json](src/IndustryFaqPage.meta.json)。

## 行业属性模板原型

在“产品管理 → 属性模板”点击“新增自定义模板”。“产品属性”页签的“选择行业属性模板”可在左侧按分类或产品名筛选，也可点击分类查看该分类下所有产品的属性；支持跨产品选择属性项，每项加入模板一行。“规格类型”页签的“选择行业属性值规格”可展开查看规格的全部可选值，选中后整组值加入模板一行。第一期示例行业固定为“汽车制造行业 → 汽车零部件”。保存后可在列表中继续编辑；同一来源项不能重复加入。

FAQ 生成、行业属性模板、产品详情规范与荣誉资质规范的完整方案见 [行业知识资产与业务使用场景方案](docs/行业产品知识资产与属性模板方案.md)。产品详情规范与荣誉资质规范本期仅作文档，不做页面。属性模板的原型端点映射在 [AttributeTemplatePage.meta.json](src/AttributeTemplatePage.meta.json)。

汽车零部件属性来自提供的 Excel 总索引及对应产品工作簿，共 10 个系统分类、95 个产品条目、2470 个字段，数据快照在 `src/data/automotive-attributes.json`。分类如 `SYS-01_动力系统`，下面展示点火线圈、附件皮带等产品。Excel 的“数据项/字段名、字段类型、说明、示例值”分别映射到页面的“属性名、类型、说明、示例值”；后两列选填，可在导入后修改，保存时保留。
